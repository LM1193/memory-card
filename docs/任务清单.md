### 9.1 解决的三个真实问题

| # | 问题 | 证据 | 修复 |
|---|---|---|---|
| 1 | 构建时脚本仍在编译 → 构建直接失败 | Editor.log：`Error building Player because scripts are compiling` → `[MCP Build] ✗ Build failed: WebGL` | 新增 `Assets/Editor/BuildTools.cs`：构建前用 `delayCall` **非阻塞**轮询 `isCompiling / isUpdating / isPlaying`，全部空闲后才执行构建；播放模式自动退出 |
| 2 | 配对瞬间会打断翻面动画，卡牌被**永久锁定在背面贴图** | 运行测试：两张同号牌连续点击后 `state=Matched` 但 `sprite=card_back` | `Card.StopAnimations()` 增加**目标贴图提交**：停止协程前若有一次未完成的翻面，先写入目标图再复位 |
| 3 | 播放中途发生域重载后 `GameManager.Instance` 变为 null，点 Start 无响应 | 实测 `InstanceIsNull=True` 而物体存活、`hasAudioSource=True`（Awake 已执行） | 单例改为**惰性自愈**属性：为空时按需 `FindObjectOfType` 重新找回 |
